01 / OVERVIEW

THE CHALLENGE

The challenge was not to design an icon set from scratch, but to animate the platform's already existing static icons. This was crucial to preserve component recognition and familiarity for existing users, while making complex ad formats immediately understandable through motion. Each icon needed to visually communicate what happens when a user interacts with its corresponding component, serving both as a UX guide and a visual identity element across the platform.

About Somplo

Somplo is a creative management platform (CMP) that enables brands and agencies to build, launch, and measure high-impact interactive display advertising — from rich media and HTML5 banners to advanced formats like parallax, video, and gamified units. The platform hosts a library of reusable creative components, each representing a unique interactive ad mechanic. To help users quickly identify and select the right component, each one needed a clear, expressive animated icon — a miniature visual demo that tells you exactly what the component does at a glance. As part of my broader creative role at Somplo, I also developed promo videos, marketing materials, and contributed to the platform's visual identity, supporting the company's overall growth and Google Partner status.

04 / APPROACH

DESIGN APPROACH

The icons were crafted as a unified system — consistent line weight, grid proportions, and animation timing across all components. Delivered in multiple formats for maximum platform compatibility.

Design Principles

  • The first static frame remains strictly identical to the original static icon, with all animations built entirely off of this starting point
  • Unified 1.8px stroke weight and 4px border-radius grid across the entire icon library
  • Each animation loop tells a complete micro-story: action → feedback → reset
  • Grayscale default state, signature Somplo blue (#00AEEF) on hover / active
  • Animations timed at 60fps with ease-in-out easing for natural feel
  • Delivered in Lottie JSON, dotLottie, SVG, and GIF for maximum compatibility
