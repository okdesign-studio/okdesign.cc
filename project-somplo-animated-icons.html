Creative Components — Animated Icons

Client: Somplo
Year: 2024–2025
Creative Execution: Oleksandr Kukharyk
EXPLORE FULL CASE
01 / OVERVIEW

THE CHALLENGE

Design and animate a complete icon set for every interactive component on the Somplo CMP platform — making complex ad formats immediately understandable through motion. Each icon needed to visually communicate what happens when a user interacts with its corresponding component, serving both as a UX guide and a visual identity element across the platform.

About Somplo

Somplo is a creative management platform (CMP) that enables brands and agencies to build, launch, and measure high-impact interactive display advertising — from rich media and HTML5 banners to advanced formats like parallax, video, and gamified units. The platform hosts a library of reusable creative components, each representing a unique interactive ad mechanic. To help users quickly identify and select the right component, each one needed a clear, expressive animated icon — a miniature visual demo that tells you exactly what the component does at a glance.

04 / APPROACH

DESIGN APPROACH

The icons were crafted as a unified system — consistent line weight, grid proportions, and animation timing across all components. Delivered as Lottie JSON for web playback and SVG for static use cases.

Design Principles

  • Unified 1.8px stroke weight and 4px border-radius grid across all icons
  • Each animation loop tells a complete micro-story: action → feedback → reset
  • Grayscale default state, signature Somplo blue (#00AEEF) on hover / active
  • Animations timed at 60fps with ease-in-out easing for natural feel
  • Delivered in Lottie JSON, SVG, and GIF for maximum platform compatibility

Deliverable Formats

LOTTIE JSON
Web animation, scalable, interactive control
SVG
Static UI, fully scalable, CSS-styleable
