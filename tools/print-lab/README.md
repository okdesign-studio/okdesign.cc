# Print Lab · студия OK Design

Исходники 3D-студии и общего движка демо. Это каталог полиграфических форматов с моделями, которые складываются, плюс публикация клиентских демо прямо на сайт.

## Что где на сайте

- `/studio/`: студия. Скрытая страница: `noindex`, ссылок с сайта нет, в `sitemap.xml` её нет.
  - Открывается только по паролю студии (`src/ui/lock.js`).
  - Токен GitHub хранится в браузере только зашифрованным этим паролем: AES-GCM, ключ из PBKDF2-SHA-256 (`src/export/vault.js`).
  - При первом входе на устройстве токен проверяется на GitHub: он должен иметь право записи в репозиторий.
- `/model/#/f/<формат>?size=…`: пустая модель формата для клиента. Публичная страница вне студии, пароль не нужен.
- `/viewer/`: собранный движок (`viewer.js`, `viewer.css`, `viewer.runtime.js`, `vendor/`, `thumbs/`). Вручную не правится, только через `npm run build`.
- `/demo/<имя>/`: одно демо для клиента. В папке лежат:
  - `index.html`: мета-теги, данные и ссылка на `/viewer/`;
  - `demo.json`: те же данные, студия читает их для списка и редактирования;
  - `outside.jpg`, `inside.jpg`, `page-N.jpg`: макет;
  - `og.jpg`: превью ссылки;
  - вложения.
  Эти папки создаёт студия. Шаблоны из каталога демо не трогает: в демо записан только id формата.
- `/heybear/`, `/nathalie-rob/…`: старые адреса. Теперь это редиректы на `/demo/…`.

## Что где в исходниках

- `src/catalog.js`: все форматы, размеры, бумага, названия.
- `src/templates/`: развёртки. Каждая описана как панели и сгибы в миллиметрах.
- `src/core/die.js`: описание развёртки. Из него получаются 3D-модель, линии реза и биговки, шаблоны PDF и SVG, разметка макета.
- `src/core/stocks.js`: бумага и картон.
- `src/viewer/`: 3D-сцена, складывание, материалы, наклейка-печать.
- `src/art/`: чтение PDF и картинок, подгонка макета (`place.js`), ориентация панелей (`orient.js`).
- `src/export/`:
  - `template.js`: шаблоны PDF и SVG с подписями и стрелками «верх»;
  - `demo.js`: сборка папки демо;
  - `publish.js`: запись в GitHub через API;
  - `vault.js`: токен под паролем студии;
  - `proof.js`: офлайн-файл HTML.
- `src/ui/`:
  - `studio.js`: панель формата;
  - `home.js`: список демо и настройки доступа;
  - `lock.js`: экран входа;
  - `catalog.js`: сетка каталога;
  - `print-lab.css`: стили.
- `src/main.js`: точка входа. Одна сборка обслуживает `/studio/`, `/model/` и страницы `/demo/…`.

## Как собрать

```
cd tools/print-lab
npm install
npm run build        # пишет в ../../viewer/
```

Картинка формата для каталога (нужен Playwright):

```
NODE_PATH=$(npm root -g) node scripts/thumbs.cjs my-format-id   # пишет в ../../viewer/thumbs/
```

## Как добавить формат

Если подходит существующая развёртка, достаточно новой записи в `src/catalog.js`: размеры, бумага, категория. Новая развёртка пишется в `src/templates/`:

```js
export function myFold({ w, h }) {
  const d = new Die({ bleed: 3, safe: 4 });
  d.root('back', 0, 0, w / 2, h, { name: 'Back', nameIn: 'Inside right' });
  d.add('back', 'right', 'front', { d: w / 2, angle: 179, seq: 1, open: 60, name: 'Front', cover: true });
  return d.finish();
}
```

- `angle` больше нуля: внутренние стороны сходятся. Меньше нуля: сходятся внешние.
- `seq`: порядок складывания.
- `gap`: сколько слоёв бумаги лежит внутри этого сгиба.
- `open`: угол в состоянии Open.

После этого:

1. `npm run build`.
2. Рендер картинки для каталога.
3. Проверка на локальном сервере из корня сайта: `python3 -m http.server`, потом `/studio/#/f/<id>`.
4. Коммит `src/`, `viewer/`, `viewer/thumbs/<id>.webp`.

## Путь заказа

1. В студии открыть формат из каталога. Вкладка «Формат»: размер и бумага.
2. На вкладке «Макет» видно, какого размера и в каком порядке страниц нужен файл. Там же скачиваются шаблоны PDF и SVG 1:1 для внешней и внутренней стороны.
3. Макет бросается на вкладку «Макет» или прямо на модель. Многостраничный PDF раскладывается по панелям сам.
4. Вкладка «Демо»: имя ссылки, тексты, кнопки, вложения → «Опубликовать демо». Через минуту-две ссылка `okdesign.cc/demo/<имя>/` работает.
5. Список демо с кнопками «Редактировать» и «Снять» есть вверху `/studio/`.

## Что важно помнить

- Цвета на экране приблизительные. CMYK из PDF показывается как RGB.
- Размеры панелей и припуски проверяются по шаблону конкретной типографии перед печатью.
- Спот-лак, фольга и тиснение пока не показываются.
- Демо не в поиске (`noindex`), но открываются у любого, у кого есть ссылка.
- Репозиторий публичный: файлы демо, включая `demo.json` с именем клиента, видны на GitHub. Снятое демо остаётся в истории.
